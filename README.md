# Voidly ChatGPT Action (historical)

This repository preserves an early OpenAPI example for a Voidly custom GPT Action. Its bundled `openapi.yaml` is **not the current Voidly API specification**. It covers three public data routes and contains historical descriptions and example response fields.

For a new integration, start with the [current API documentation](https://voidly.ai/api-docs) and [current OpenAPI specification](https://voidly.ai/openapi.json). Check each endpoint's authentication requirements and test its live response before importing a schema into ChatGPT. Public data reads are available without a key; other endpoints may require one.

Custom GPT creation and Action configuration depend on your ChatGPT workspace permissions. See [OpenAI's current GPT setup guidance](https://help.openai.com/en/articles/8554397-creating-and-editing-gpts).

The historical schema and [MIT license](LICENSE) remain here for reference.
